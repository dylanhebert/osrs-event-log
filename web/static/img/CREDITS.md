content is CC BY-NC-SA 3.0. This is a non-commercial fan project for a private
Discord community and the site is not public, which is the basis for using it
here. Swap it for something original if that ever stops being true.

cut off; the header keeps the original proportions instead, since it has the
room.

To regenerate after replacing the source image, see the recipe in
`docs/web-ui.md`.
